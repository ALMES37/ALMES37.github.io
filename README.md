# Широков Иван (ALMES37) — портфолио

Личный сайт-портфолио: сайты и дизайн под заказ. Палитра — чёрный графит, тёмно-синий и серебро. Чистые HTML, CSS и JavaScript, анимации — GSAP 3.12.5 с CDN. Сборка не нужна.

## Что внутри

1. **Первый экран** — серебряный «экран» на графитово-синей сцене. При первом заходе на нём печатается терминал («автор: засекречено»), потом экран включается, как старый монитор. Оптоволоконные нити скручены в провод, светящиеся кончики тянутся к курсору, клик — вспышка. Имя зашифровано. Экран — шлифованное серебро с бликом, который едет за мышкой. При прокрутке экран раскрывается на весь монитор, серебро перетекает в тёмно-синюю ночь, провод раскручивается, нити серебрятся и разлетаются в стороны — и начинается сайт.
2. **Кто за экраном** — фото собирается из графитово-сине-серебряных пикселей (медленно, по ходу прокрутки), имя расшифровывается по буквам. Ниже — лента фотографий.
3. **Сайты** — стеклянные карточки: Audi (живой рентген в карточке), ALMES shop (переключатель трёх стилей), пирамида 3D (наклон за мышкой). Блок «Для клиентов» — «стань первым».
4. **Дизайн** — список услуг, живой постер Audi RS 7 ABT в стиле «битые данные», переключатель «мои работы / на заказ» (пока «в разработке»).
5. **Связь** — кнопки Telegram-канал, Telegram, ВКонтакте, почта.
6. **Подвал** — большой хромированный ник ALMES37.

## Как вставить ссылки на соцсети

Открыть `js/main.js`, в самом верху заполнить:

```js
const LINKS = {
  tgChannel: 'https://t.me/имя_канала',
  tg: 'https://t.me/твой_ник',
  vk: 'https://vk.com/твой_адрес',
  mail: 'mailto:почта@пример.ru',
};
```

Пустая строка — кнопка показывает «Ссылка появится совсем скоро». Принимаются только адреса `https://…` и `mailto:…`.

## Как добавить работу

- Сайт для клиента — скопировать любую `<article class="card">` из раздела «Сайты», поменять картинку, тексты и ссылку. Блок `.empty` («стань первым») удалить, когда появится первая работа.
- Дизайн — блок `.shelf` в разделе «Дизайн».

## Как запустить локально

```bash
python -m http.server 5180
```

Открыть http://localhost:5180. Если открыть `index.html` двойным кликом, почти всё работает, но фото в блоке «Кто за экраном» будет собираться без сине-серебряной палитры: браузер не даёт читать пиксели файлов с диска.

## Файлы

| Файл | Что в нём |
|---|---|
| `index.html` | Разметка и тексты |
| `css/style.css` | Цвета, шрифты, вёрстка |
| `js/main.js` | Ссылки на соцсети, загрузка, переход с первого экрана, карточки |

## Обновления

Адрес сайта всегда один — https://almes37.github.io/. После `git push` GitHub пересобирает сайт за 1–2 минуты, и все, у кого есть ссылка, видят новую версию. Браузер хранит файлы до 10 минут, поэтому при каждом обновлении нужно менять номер версии `?v=…` у `css/style.css` и `js/*.js` в `index.html` — тогда посетители сразу получат новые файлы.
