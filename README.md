# Широков Иван (ALMES37) — портфолио

Личный сайт-портфолио: сайты и дизайн под заказ. Идея оформления — «ручная сборка», как у машин:
хромированный шильдик ALMES37, шлифованный алюминий, тёмно-синяя ночь и свет студии.
Чистые HTML, CSS и JavaScript, анимации — GSAP 3.15 (лежит в `js/vendor`, без внешних серверов). Сборка не нужна.

## Что внутри

1. **Заставка** — темнота, полоса света вытягивается поперёк экрана, раскрывается на две и открывает хромированный ALMES37, по буквам проходит блик. Потом экран мигает и включается серебром. Клик, клавиша или колесо мыши ускоряют заставку.
2. **Первый экран** — серебряный экран с шильдиком. Возле надписи хром блестит вокруг курсора (на телефоне — под пальцем), раз в несколько секунд по нему сам пробегает блик. При прокрутке экран раскрывается в ночь, а шильдик уезжает наверх и садится в шапку.
3. **Кто за экраном** — буквы ALMES37 переворачиваются, как на табло, в ШИРОКОВ, следом появляется ИВАН. Фото собирается из пикселей. Ниже лента фотографий, она едет вбок при прокрутке.
4. **Сайты** — Audi (живой рентген), ALMES shop (колода из трёх витрин, переключается кнопками или кликом), пирамида 3D (наклон за мышкой). Блок «Для клиентов» — пустое парковочное место «01», вид сверху: сюда встанет первая работа.
5. **Конфигуратор** — крышка ноутбука открывается при прокрутке, внутри настоящие сборки из конфигуратора, стили переключаются кнопками.
6. **Дизайн** — список услуг и живой постер Audi RS 7 ABT «битые данные».
7. **Связь** — Telegram, Telegram-канал и ВКонтакте.
8. **Подвал** — большой хромированный ALMES37, хром блестит вокруг курсора.

Шапка: белая капсула ездит под активным разделом и заглядывает на пункт при наведении. Когда раздел сменился, по её хромированному канту один раз прокатывается отражение.

### Как всё появляется

Три приёма, у каждого своя работа, и больше ничего не анимируется:

- **Заголовки** выезжают по строкам из-под маски (`data-reveal="lines"`), по серебряным потом проходит блик.
- **Фото и постер** открываются снизу вверх, как ворота гаража (`data-media`).
- **Списки** (табличка «Делаю / Инструменты», услуги, ссылки в «Связи») прочерчиваются слева направо, как линии на чертеже (`data-reveal="rows"`).

Обычный текст стоит на месте: его читают, а не смотрят.

### Переходы

Клик по пункту меню: две тёмные шторки смыкаются к полосе света (заставка наоборот), страница перескакивает к разделу, шторки расходятся. Кнопки «Открыть сайт» и «Открыть конфигуратор» (атрибут `data-leave`) открывают проект в этой же вкладке, но сначала закрываются шторки. Если вернуться кнопкой «Назад», шторки расходятся, и страница стоит там же, где была. С клавиатуры и по Ctrl/Cmd-клику переходы обычные, без шторок.

Если в системе включено «уменьшить движение», шторок и выездов нет, всё сразу на месте.

## Как вставить ссылки на соцсети

Открыть `js/main.js`, в самом верху заполнить:

```js
const LINKS = {
  tgChannel: 'https://t.me/имя_канала',
  tg: 'https://t.me/твой_ник',
  vk: 'https://vk.com/твой_адрес',
  mail: 'mailto:почта@пример.ru',
};
```

Пустая строка — пункт в «Связи» спрятан. Принимаются только адреса `https://…` и `mailto:…`.

## Как добавить работу

- Сайт для клиента — скопировать любой `<article class="proj">` из раздела «Сайты», поменять картинку, тексты и ссылку. У ссылки на свой сайт оставить атрибут `data-leave` (переход через шторки). Блок `.vacant` («Место свободно») удалить, когда появится первая работа.
- Дизайн — в раздел «Дизайн», рядом с постером. Подборку лучше показывать, когда наберётся хотя бы 3–4 работы.
- Тексты: после коротких слов (в, и, с, на, для…) ставить `&nbsp;` вместо пробела, чтобы предлог не висел в конце строки.
- Картинки лучше класть в трёх видах: `.avif` и `.webp` (лёгкие) плюс `.jpg` как запасной вариант, как сделано у остальных фото.

## Как запустить локально

```bash
python -m http.server 5180
```

Открыть http://localhost:5180. Если открыть `index.html` двойным кликом, почти всё работает, но фото в блоке «Кто за экраном» будет собираться без сине-серебряной палитры: браузер не даёт читать пиксели файлов с диска.

## Обновления

Адрес сайта всегда один — https://almes37.github.io/. После `git push` GitHub пересобирает сайт за 1–2 минуты, и все, у кого есть ссылка, видят новую версию. Браузер хранит файлы до 10 минут, поэтому при каждом обновлении нужно менять номер версии `?v=…` у `css/style.css` и `js/*.js` в `index.html` — тогда посетители сразу получат новые файлы.
